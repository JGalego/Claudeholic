# Creative Brief: Case File 001

## Project vision

**claudeholic.me** is a beautifully overfunded public-health intervention for
people who opened Claude "for one question." It is simultaneously a parody, a
love letter, a cautionary tale, and a useful guide to living well with
generative AI.

The experience moves through three beats:

1. Recognition: "This is funny."
2. Exposure: "This is specifically about me."
3. Recalibration: "I could probably close the laptop for ten minutes."

## Core philosophy

- The visitor is always in on the joke.
- Claude is neither villain nor deity. It is a capable tool we keep giving
  emotional office hours.
- Useful guidance is smuggled inside satire.
- Complexity must justify itself through meaning, delight, or accessibility.
- Privacy is practiced, not merely recommended.
- The experience never presents itself as a real diagnosis.
- The implementation irony is canon: the Claude intervention was built with
  GitHub Copilot. The committee found no conflict of interest.

## Information architecture

1. **Case-file hero:** One harmless question becomes an evening.
2. **Dependency check:** Twelve symptoms produce a local Prompt Withdrawal
   Index without sending data anywhere.
3. **Stages:** A complete clinical-style progression, with the visitor's stage
   highlighted when JavaScript is available.
4. **Recovery program:** Small, practical interventions disguised as
   paperwork.
5. **Balance manifesto:** A quiet and sincere case for craft, skepticism,
   learning, privacy, and human creativity.
6. **Department records:** Footnotes, achievements, hidden lore, and sparse
   sister-project callbacks.
7. **Colophon:** Disclaimer, provenance, privacy, and a final suggestion to
   leave.

The page remains complete and understandable without JavaScript.

## Visual language

The governing concept is **luxury editorial meets underfunded government
form**. Large serif statements, document grids, registration marks, evidence
stamps, checkboxes, terminal annotations, and generous full-width bands create
the visual system. The assessment is an intake form, not a pile of cards.

A custom Department of Prompt Health seal and procedural diagrams provide the
visual identity. Official Anthropic marks are not imitated.

## Tone guide

The institutional voice is calm, precise, and mildly concerned. Humor targets
our habits, never the visitor.

- Prefer short declarative sentences.
- Use specificity instead of meme references.
- Let bureaucratic understatement carry the joke.
- Acknowledge anthropomorphism when using it.
- Keep practical advice concrete and evidence-minded.
- Let the manifesto be sincere without interrupting every thought with a joke.

## Color and typography

- Intake Paper `#F3EFE6`: primary surface.
- Carbon `#171714`: text and terminal ground.
- Alert Vermilion `#A93F2D`: warnings, stamps, and active states.
- Recovery Green `#245C45`: constructive guidance.
- Verification Blue `#145C9E`: links and evidence.
- Administrative Yellow `#E6B84A`: highlights, never body text.
- Terminal Signal `#B8D96A`: sparse terminal output.

Newsreader carries editorial moments. IBM Plex Mono handles controls,
metadata, and terminal output. Both are self-hosted, subset WOFF2 assets with
carefully matched fallbacks.

## Motion principles

Motion behaves like administrative theater: restrained until a tiny action
receives wildly disproportionate processing.

- Use one staged hero entrance and immediate assessment feedback.
- Reserve the oversized loading bar for the panic procedure.
- Avoid parallax, autoplay media, flashing, and endless ambient motion.
- Prefer transforms and opacity.
- Make every result immediate under `prefers-reduced-motion`.
- Never hide readable content while enhancement code loads.

## Easter eggs and hidden lore

Discoveries have four layers: ordinary interactions, keyboard or repeated-logo
input, terminal commands, and source comments. Repeat visits may unlock a
local-only achievement. There is no surprise audio or inaccessible hidden
content.

The Department of Prompt Health publishes the site. Its Bureau of Context
Hygiene administers the Prompt Withdrawal Index using the unreviewed DSM-AI.
The International Claudeholics Association is an independent peer group.
Certified Context Window Inspectors issue case numbers. The Ministry of Token
Conservation exists deeper in the records.

## Technical architecture

- Semantic HTML, modern CSS, and small native ES modules.
- No framework, bundler, service worker, analytics, runtime API, or third-party
  script.
- Content lives in HTML for search visibility and no-script resilience.
- JavaScript enhances scoring, achievements, terminal mode, and local-only
  visit state.
- Accessibility includes landmarks, labels, focus states, live regions, a skip
  link, and keyboard-complete controls.
- Metadata includes canonical, Open Graph, sitemap, robots, structured data,
  and an explicit parody/non-affiliation statement.
- A dependency-free Node script validates local references and required
  metadata.

## Deployment

GitHub Pages deploys from `main` through the official Pages Actions. The
workflow validates the static site before uploading it, uses deployment
concurrency, and requires no build step. `CNAME`, `.nojekyll`, and a custom 404
page complete the static deployment.

## Content and repository strategy

The homepage carries the complete narrative: twelve escalating symptoms, six
stages, seven useful recovery actions, and one sincere manifesto. Sister
projects receive exactly three understated appearances: `vibecode` in the
terminal dependency tree, `works-on-my-machine` in 404 diagnostics, and
`tech-debt` in a hidden achievement or source comment.

Runtime assets live under `assets/`; creative and accessibility decisions live
under `docs/`; dependency-free checks live under `scripts/`; community and
deployment files live under `.github/`. Code uses the MIT License. Original
prose and artwork use CC BY 4.0.
