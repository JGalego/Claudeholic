# claudeholic.me Launch Kit

## One-line description

One question. Several hours. A satirical intervention for healthier generative
AI use.

## Short description

claudeholic.me is a static, privacy-respecting self-assessment for people whose
harmless AI prompt became an evening. It pairs dry satire with practical advice
about verification, privacy, fundamentals, attention, collaboration, and human
creativity.

## Verified facts

Use these claims exactly. They describe the current implementation.

- Static HTML, CSS, and native JavaScript modules on GitHub Pages.
- No analytics, cookies, accounts, advertising, or remote application API.
- Individual checkbox selections are processed in memory and are not persisted.
- Coarse assessment milestones, unlocked achievements, a visit count, and
  one-session detection are retained automatically in disclosed browser storage.
- Assessment reports are generated locally as semantic, keyboard-operable HTML,
  copyable text, and a downloadable 1200 × 630 PNG.
- Shared text contains the aggregate score and stage, never the symptom list.
- Core reading and manual scoring work without JavaScript; reports, automatic
  scoring, achievements, and the terminal are progressive enhancements.
- Animations respect `prefers-reduced-motion`.
- Department Bulletins and an RSS feed provide occasional practical guidance.
- Public community intake occurs through account-linked GitHub issues; the
  approved static field-note ledger omits contributor identities.
- The project is independent and not affiliated with Anthropic.
- The project was built with GitHub Copilot. This is disclosed because irony
  should have provenance.

Do not claim that the assessment is medical, scientific, clinically validated,
anonymous, or endorsed by Anthropic.
